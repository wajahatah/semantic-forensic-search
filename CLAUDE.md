## Architecture

**Pipeline (offline → online):**
1. **Manifest** (`sfs.data.manifest`) — MEVA annotations ↔ video; Protocol A (official split) and Protocol B (unseen cameras).
2. **Sampling + regions** (`sfs.data.sampling`, `sfs.data.regions`) — 2 fps, cap 16 frames; views `tight` / `context` / `full` from per-frame actor boxes.
3. **Embedding** (`sfs.embed.run`, `sfs.embed.encoder`) — frozen SigLIP / SigLIP 2, per-video resumable shards (`sfs.store.shards`).
4. **Crop store** (`sfs.data.extract_crops`, `sfs.store.crops`) — tight = native PNG, context = ≤448 px JPEG; packed per video.
5. **Evaluation** (`sfs.eval.*`) — Q1 category / Q2 forensic queries, mAP, P@10, Recall@K, MRR.
6. **Planned:** LoRA adaptation of SigLIP 2; VLM teacher → temporal student re-ranker (distillation); alert ingestion + search demo (ChromaDB vectors + SQLite metadata).
